# ✅ Conclusiones y Recomendaciones — SGAT

## 1. Conclusiones

- El prototipo navegable del SGAT permite visualizar de forma clara el flujo de registro, asignación, mantenimiento y control de garantías de los activos tecnológicos, cumpliendo con los requerimientos funcionales definidos en las etapas iniciales del proyecto.
- La arquitectura de tres capas (presentación, lógica de negocio y datos) resultó adecuada para separar responsabilidades y facilitar el mantenimiento futuro del sistema.
- El modelo entidad-relación y el diagrama de clases diseñados brindan una base sólida para una eventual implementación completa del backend y la base de datos.
- La estimación mediante puntos de función y COCOMO II permitió dimensionar de forma realista el esfuerzo y el tiempo de desarrollo requeridos para un proyecto académico de este alcance.
- El uso de Git y GitHub como herramientas de control de versiones facilitó la trazabilidad de los cambios realizados en el código y en la documentación del proyecto.

## 2. Recomendaciones

- Continuar con la implementación del backend y la base de datos relacional para transformar el prototipo visual en una aplicación funcional completa.
- Reforzar la seguridad del sistema mediante mecanismos de autenticación robustos (por ejemplo, hash de contraseñas y control de sesiones) antes de un despliegue en producción.
- Ampliar las pruebas automatizadas para cubrir de forma más exhaustiva los casos de uso críticos del sistema.
- Mantener actualizada la documentación técnica conforme evolucione el sistema, especialmente el modelo de datos y los diagramas de secuencia.
- Establecer un cronograma de mantenimiento periódico desde las primeras etapas de producción, siguiendo lo definido en el plan de mantenimiento.

## 3. Alcance logrado

El proyecto cumple con los objetivos planteados para esta etapa: manual de usuario, manual técnico, evidencias de pruebas, plan de mantenimiento, plan de gestión de configuración, control de versiones mediante Git y las presentes conclusiones y recomendaciones.
