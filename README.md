# 🖥️ SGAT-Prototipo

Sistema de Gestión de Activos Tecnológicos (SGAT) — Prototipo navegable y documentación técnica del proyecto académico (Universidad San Marcos, Ingeniería de Software II).

## 📌 Descripción general

El SGAT es una aplicación web de tres capas (presentación, lógica de negocio y datos) que permite centralizar la información de los activos tecnológicos, sus asignaciones, mantenimientos, garantías y bitácora de cambios, garantizando trazabilidad y seguridad en el manejo del inventario institucional.

## 🚀 Demo del prototipo

El prototipo navegable se encuentra en el archivo `sgat-prototipo.html`. Puede clonarse el repositorio y abrirse directamente en el navegador.

Usuarios de prueba: `project.manager`, `developer`, `qa`, `admin`.

## 🔀 Control de versiones

Este proyecto utiliza **Git** como herramienta de control de versiones, siguiendo convenciones de commits semánticos:

- `feat:` nuevas funcionalidades
- `fix:` corrección de errores
- `docs:` cambios en documentación
- `test:` evidencias y pruebas
- `chore:` tareas de mantenimiento del repositorio

Se recomienda revisar el historial de commits, ramas y releases como evidencia del proceso de desarrollo incremental.
